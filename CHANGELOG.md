# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](https://semver.org/lang/ru/).

## [1.0.0] — 2026-08-26

Первый публичный выпуск.

### Добавлено

- `bootstrap` — регистрация integration module и выпуск `mgBot`-токена
  через `integrations[mgBot][refreshToken]`, с записью в `.env` (`chmod 600`).
- Защита от перевыпуска чужого токена: проверка существующего модуля,
  флаги `--refresh` и `--force`.
- `doctor` — сквозная проверка конфигурации, ключа RetailCRM и доступа к MG.
- Клиент MessageGateway Bot API: каналы, чаты, диалоги, сообщения, участники,
  клиенты, операторы; курсорная пагинация по `since_id`.
- `export` — выгрузка переписок в JSON, JSONL и Markdown.
- Команды `config`, `modules`, `channels`, `chats`, `dialogs`, `messages`;
  флаг `--json` у всех листингов.
- HTTP-слой на стандартной библиотеке: ретраи для `429` и `5xx`,
  типизированные ошибки, вырезание `apiKey` из логируемых URL.
- Маскирование секретов во всём выводе.
- Автоопределение адреса MessageGateway из ответа RetailCRM (`endpointUrl`),
  с ручным указанием через `--mg-api-base`, если CRM его не вернула.
- Нормализация адресов: схема `https://` подставляется, хвост `/api/v5`
  у адреса CRM отрезается, путь `/api/bot/v1` у адреса MG дописывается.
- Общие флаги (`--env-file`, `--base-url`, `--mg-api-base`) работают
  и до подкоманды, и после неё.
- Документация: быстрый старт, архитектура, справочник API и CLI, разбор ошибок.

### Важно

- Адресов по умолчанию нет. `RETAILCRM_BASE_URL` и `RETAILCRM_MG_API_BASE`
  привязаны к конкретному аккаунту, поэтому коннектор их не угадывает:
  команда, которой адрес нужен, скажет об этом и завершится с кодом `2`.
